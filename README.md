# 모바일 명함 메이커

이름과 전화번호만 넣으면 **카톡으로 보내는 모바일 명함**을 만들어 주는 작은 도구예요.
설치도, 서버도, 코딩도 필요 없어요. 만들기 페이지에서 정보를 넣고 zip 파일을 받아 무료 호스팅에 올리면 끝이에요.

- **만들기 페이지**: https://songbyeongseung11-max.github.io/mobile-card-maker/
- **완성 예시 보기** (가상의 인물): https://songbyeongseung11-max.github.io/mobile-card-maker/example/

받는 사람은 링크 하나로 이렇게 할 수 있어요.

- **연락처 저장하기**: 이름 · 회사 · 직함 · 번호 · 이메일이 채워진 저장 화면이 바로 떠요 (아이폰 · 안드로이드)
- **전화하기 · 문자하기**: 누르면 바로 연결돼요
- **내 사진**: 이름 위에 동그란 프로필 사진이 들어가요 (선택)
- **사진 갤러리**: 행사 · 작업 · 매장 사진을 옆으로 넘겨 보고, 누르면 크게 봐요 (선택, 최대 10장)
- **바로가기 버튼**: 인스타그램, 홈페이지, 행사 안내문 · 유튜브 · 예약 페이지 같은 링크 2개까지 (선택)
- **카카오톡으로 명함 보내기** (선택): 큰 이미지와 [모바일 명함 보기] [연락처 저장] 버튼이 달린 카드로 전달돼요
- 카톡에 링크를 붙이면 **미리보기 이미지 카드**가 떠요

## 1. 명함 만들기

1. 이 저장소의 `index.html`을 브라우저로 열어요. (GitHub Pages를 켰다면 그 주소로 들어가요.)
2. 이름, 회사, 번호, 인사말을 넣고 사진, 링크, 색, 로고를 골라요. 오른쪽에서 바로 미리 볼 수 있어요.
   - 사진은 휴대폰에서 빨리 열리도록 자동으로 줄여서 넣어요 (프로필 480px, 갤러리 1400px).
   - 인스타그램은 `@아이디`만 넣어도 주소로 바꿔 줘요.
3. **명함 파일 받기 (zip)** 를 눌러요.

zip 안에는 이런 파일이 들어 있어요.

```
mobile-card/
├─ index.html     명함 페이지
├─ contact.vcf    연락처 저장 파일
├─ _headers       휴대폰이 연락처 파일을 알아보게 하는 Netlify 설정
└─ img/           로고 · 미리보기 · 내 사진 · gallery/ 사진들 (넣은 경우)
```

## 2. 인터넷에 올리기 (무료)

### Netlify (가장 쉬움)
1. [netlify.com](https://www.netlify.com) 에 가입해요. 구글 계정으로 가입하면 빨라요.
2. [app.netlify.com/drop](https://app.netlify.com/drop) 에 압축을 푼 `mobile-card` **폴더째** 끌어다 놓아요.
3. 사이트 설정에서 이름을 바꾸면 `https://내이름.netlify.app` 같은 주소가 돼요.
4. 새 사이트가 '비공개'로 만들어지면 **Project configuration → Visibility → Public** 으로 바꿔요.

> zip 파일을 직접 올릴 때는 윈도우 기본 압축이 아니라 이 도구가 만든 zip을 그대로 쓰세요. 윈도우 탐색기로 다시 압축하면 이미지 경로가 깨질 수 있어요.

### GitHub Pages
`mobile-card` 폴더 내용을 새 저장소에 올리고 **Settings → Pages** 에서 켜면 돼요. (GitHub Pages는 `_headers`를 쓰지 않아서 일부 안드로이드 기기에서 연락처 저장이 덜 매끄러울 수 있어요.)

## 3. 카톡 미리보기 이미지 띄우기

카톡은 링크 미리보기에 **전체 주소가 적힌 이미지**가 필요해요.
주소가 생긴 뒤 만들기 페이지의 **올릴 주소** 칸에 그 주소를 넣고 zip을 한 번 더 만들어 다시 올려 주세요.

- 미리보기 이미지는 1200×630 크기가 가장 잘 보여요.
- 카톡은 한 번 본 미리보기를 한동안 기억해요. 바꾼 뒤 예전 이미지가 보이면 주소 뒤에 `?v=2`를 붙여 보내 보세요.

## 4. 카카오톡 공유 버튼 (선택)

1. [developers.kakao.com](https://developers.kakao.com) 에 카카오 계정으로 로그인하고 **앱 생성**을 눌러요.
2. **앱 → 플랫폼 키 → JavaScript 키** 에서 **JavaScript SDK 도메인**에 내 명함 주소를 등록해요.
3. **앱 → 제품 링크 관리 → 웹 도메인** 에도 같은 주소를 등록해요.
4. JavaScript 키를 복사해서 만들기 페이지의 **카카오 JavaScript 키** 칸에 넣고 zip을 다시 만들어 올려요.

JavaScript 키는 웹페이지에 공개되도록 만들어진 키라 명함에 들어가도 괜찮아요. 등록한 주소에서만 동작해요. (REST API 키나 어드민 키는 절대 넣지 마세요.)

## 개인정보 안내

명함 페이지는 **누구나 볼 수 있는 공개 페이지**예요. 링크를 아는 사람은 이름, 전화번호, 이메일, 사진을 볼 수 있으니 공개해도 되는 정보만 넣어 주세요. 갤러리에 다른 사람이 나온 사진을 넣을 때는 그분의 동의를 받아 주세요.
만들기 페이지는 입력한 정보를 어디에도 보내지 않아요. 모든 작업이 내 브라우저 안에서만 이루어져요.
